Design concept — HRMS product suite

One quiet corporate language, six distinct rooms.

Every module shares the same ink, type, and structure — so the product never feels stitched together — but each one is tuned with its own accent and layout logic to match how that work actually gets done.

List + profile, not a card grid — this is where you look someone up, not browse.

Recruitment

A pipeline is motion, so the layout is a kanban board rather than a list. Teal is cooler and more active than the archival brass of Core HR — this is a workspace, not a record.

Columns as stages, not statuses — the board mirrors the actual hiring funnel.

Balances live beside the calendar, not buried in a separate tab.

Every cycle → what people are actually paid

Payroll

Styled like a statement, not a dashboard — a single hero figure, then a clean ledger. Forest green is the most literal accent in the suite, deliberately, because payroll rewards clarity over cleverness.

One number matters most here. Everything else is in service of it.

Ongoing → growth and contribution

Performance

The only module built around a radial form — goals are partial and cumulative, which a progress ring shows more honestly than a bar. Plum is reflective rather than clinical, fitting a conversation about growth.

Ring for the whole; a short list for the parts that make it up.

Every day → the employee's own front door

Employee Self-Service

The friendliest room in the suite — bigger tap targets, plainer language, quick actions above everything else. Cobalt is close to the corporate ink but lighter, so it still feels like the same company, just a calmer room in it.

Actions before information — most visits here are three taps, not a read.
